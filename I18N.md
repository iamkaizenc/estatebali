## Overview

Estate Bali uses a comprehensive i18n system with support for 5 languages. The system is built on top of Next.js App Router and provides:

- ✅ Type-safe translations with TypeScript
- ✅ Client and server component support
- ✅ Parameter interpolation
- ✅ RTL language support (Arabic, Hebrew)
- ✅ AI-translated content notices
- ✅ 500+ translation keys covering entire application

**Architecture:**
```
src/i18n/
├── config.ts           # Locale configuration and utilities
├── messages.ts         # All translations (1600+ lines)
├── useTranslation.ts   # Hooks and utilities
└── index.ts            # Central export point
```

## Quick Start

### Installation

All i18n dependencies are already installed. Import from `@/i18n`:

```tsx
import { useTranslation } from '@/i18n';
```

### Basic Usage (Client Component)

```tsx
'use client';

import { useTranslation } from '@/i18n';

export default function MyComponent() {
  const { t, locale, isAI } = useTranslation();

  return (
    <div>
      <h1>{t('hero.title')}</h1>
      <p>{t('hero.subtitle')}</p>

      {/* Show AI notice for non-English locales */}
      {isAI && (
        <span className="text-sm text-gray-400">
          {t('hero.aiTranslatedNotice')}
        </span>
      )}
    </div>
  );
}
```

### Basic Usage (Server Component)

```tsx
import { getTranslation, type Locale } from '@/i18n';

export default function Page({
  params
}: {
  params: { locale: Locale }
}) {
  const title = getTranslation(params.locale, 'hero.title');

  return <h1>{title}</h1>;
}
```

## Client Components

### useTranslation Hook

The `useTranslation` hook provides all functionality needed for client components.

#### Return Values

```tsx
const {
  locale,          // Current locale (e.g., 'en', 'id')
  t,               // Translation function
  tWithFallback,   // Translation with custom fallback
  hasTranslation,  // Check if translation exists
  messages,        // All messages for current locale
  isAI,            // Whether locale uses AI translation
} = useTranslation();
```

#### Translation Function (t)

**Simple Translation:**
```tsx
const { t } = useTranslation();

<h1>{t('hero.title')}</h1>
// English: "Find Your Dream Property in Bali"
// Indonesian: "Temukan Properti Impian Anda di Bali"
```

**Parameter Interpolation:**
```tsx
<p>{t('dashboard.welcome', { name: 'John Doe' })}</p>
// English: "Welcome back, John Doe!"
// Indonesian: "Selamat datang kembali, John Doe!"

<span>{t('search.results.showing', { count: 25 })}</span>
// English: "Showing 25 properties"
// Indonesian: "Menampilkan 25 properti"
```

**Nested Keys:**
```tsx
t('property.types.villa')           // "Villa"
t('auth.login.errors.emailRequired') // "Email is required"
t('booking.summary.nights', { count: 3 }) // "3 nights"
```

#### Translation with Fallback

```tsx
const { tWithFallback } = useTranslation();

<p>
  {tWithFallback(
    'experimental.newFeature',
    'This feature is coming soon',
    { days: 7 }
  )}
</p>
// If key doesn't exist, shows: "This feature is coming soon"
```

#### Check Translation Existence

```tsx
const { hasTranslation, t } = useTranslation();

if (hasTranslation('property.amenities.gym')) {
  return <p>{t('property.amenities.gym')}</p>;
}
```

#### Direct Message Access

```tsx
const { messages } = useTranslation();

// Access nested messages directly
<span>{messages.common.loading}</span>
<button>{messages.common.save}</button>
<p>{messages.property.types.villa}</p>
```

### Complete Example

```tsx
'use client';

import { useTranslation } from '@/i18n';
import { User } from '@/types';

interface PropertyCardProps {
  title: string;
  bedrooms: number;
  price: number;
  user?: User;
}

export default function PropertyCard({
  title,
  bedrooms,
  price,
  user
}: PropertyCardProps) {
  const { t, locale, isAI } = useTranslation();

  return (
    <div className="card">
      <h2>{title}</h2>

      {/* Translation with parameter */}
      <p>
        {t('property.details.bedrooms')}: {bedrooms}
      </p>

      {/* Direct message access */}
      <p className="price">
        {new Intl.NumberFormat(locale).format(price)} USD
      </p>

      {/* Conditional translation */}
      {user && (
        <p>{t('dashboard.welcome', { name: user.name })}</p>
      )}

      {/* Action buttons */}
      <div className="actions">
        <button>{t('property.actions.viewDetails')}</button>
        <button>{t('property.actions.contactAgent')}</button>
      </div>

      {/* AI notice */}
      {isAI && (
        <small className="text-gray-400">
          {t('hero.aiTranslatedNotice')}
        </small>
      )}
    </div>
  );
}
```

## Server Components

### getTranslation Function

For Server Components or API routes that need translations.

```tsx
import { getTranslation, type Locale } from '@/i18n';

export default function Page({
  params
}: {
  params: { locale: Locale }
}) {
  const title = getTranslation(params.locale, 'hero.title');
  const subtitle = getTranslation(
    params.locale,
    'dashboard.welcome',
    { name: 'User' }
  );

  return (
    <div>
      <h1>{title}</h1>
      <p>{subtitle}</p>
    </div>
  );
}
```

### getSection Function

Get an entire section of messages at once.

```tsx
import { getSection, type Locale } from '@/i18n';

export default function LoginPage({
  params
}: {
  params: { locale: Locale }
}) {
  const authMessages = getSection(params.locale, 'auth');

  return (
    <div>
      <h1>{authMessages.login.title}</h1>
      <p>{authMessages.login.subtitle}</p>

      {/* Pass to client component */}
      <LoginForm messages={authMessages.login} />
    </div>
  );
}
```

### Metadata and SEO

```tsx
import { getTranslation, type Locale } from '@/i18n';
import type { Metadata } from 'next';

export async function generateMetadata({
  params
}: {
  params: { locale: Locale }
}): Promise<Metadata> {
  const title = getTranslation(params.locale, 'hero.title');
  const subtitle = getTranslation(params.locale, 'hero.subtitle');

  return {
    title: `${title} - Estate Bali`,
    description: subtitle,
  };
}
```

## Adding New Translations

### 1. Add to Interface

First, add the key to the `Messages` interface in `src/i18n/messages.ts`:

```typescript
export interface Messages {
  // ... existing sections

  newSection: {
    title: string;
    description: string;
    action: {
      submit: string;
      cancel: string;
    };
  };
}
```

### 2. Add English Translation

Add the English translation to the `en` object:

```typescript
const en: Messages = {
  // ... existing translations

  newSection: {
    title: 'New Section',
    description: 'This is a new section',
    action: {
      submit: 'Submit',
      cancel: 'Cancel',
    },
  },
};
```

### 3. Add Indonesian Translation

Add the Indonesian translation to the `id` object:

```typescript
const id: Messages = {
  // ... existing translations

  newSection: {
    title: 'Bagian Baru',
    description: 'Ini adalah bagian baru',
    action: {
      submit: 'Kirim',
      cancel: 'Batal',
    },
  },
};
```

### 4. Update Other Languages

Update placeholder languages (he, ar, zh) or leave them to use English as fallback.

### 5. Use in Components

```tsx
const { t } = useTranslation();

<h1>{t('newSection.title')}</h1>
<p>{t('newSection.description')}</p>
<button>{t('newSection.action.submit')}</button>
```

Edit `src/i18n/config.ts`:

```typescript
export const supportedLocales = [
  'en', 'id', 'he', 'ar', 'zh',

// If RTL language
export const rtlLocales: Locale[] = ['ar', 'he'];
```

### Step 2: Create Translation Object

In `src/i18n/messages.ts`, create the new translation object:

```typescript
// Japanese Translation
const ja: Messages = {
  common: {
    loading: '読み込み中...',
    error: 'エラー',
    success: '成功',
    // ... all other translations
  },
  // ... complete all sections
};
```

### Step 3: Export New Locale

Add to exports in `src/i18n/messages.ts`:

```typescript
export const messages: LocalizedMessages = {
  en,
  id,
  ja,  // Add Japanese
  he: en,
  ar: en,
  zh: en,

```

### Step 4: Update AI Translation Check

If the new language is human-translated, update `isAITranslated`:

```typescript
export function isAITranslated(locale: Locale): boolean {
  return !['en', 'id', 'ja'].includes(locale);  // Add 'ja'
}
```

### Step 5: Test

## RTL Language Support

### Automatic RTL Detection

The system automatically detects RTL languages:

```tsx
import { isRTL } from '@/i18n';

export default function RootLayout({
  params
}: {
  params: { locale: Locale }
}) {
  const direction = isRTL(params.locale) ? 'rtl' : 'ltr';

  return (
    <html lang={params.locale} dir={direction}>
      <body>{children}</body>
    </html>
  );
}
```

### RTL-Specific Styles

```tsx
import { useTranslation, isRTL } from '@/i18n';

export default function MyComponent() {
  const { locale } = useTranslation();
  const rtl = isRTL(locale);

  return (
    <div className={rtl ? 'rtl-layout' : 'ltr-layout'}>
      {/* Content */}
    </div>
  );
}
```

### CSS for RTL

```css
/* globals.css */
[dir="rtl"] {
  direction: rtl;
}

[dir="rtl"] .text-left {
  text-align: right;
}

[dir="rtl"] .ml-4 {
  margin-left: 0;
  margin-right: 1rem;
}
```

## Best Practices

### ✅ DO

1. **Always use translation keys, never hardcode text**
   ```tsx
   ✅ <button>{t('common.save')}</button>
   ❌ <button>Save</button>
   ```

2. **Use parameter interpolation for dynamic content**
   ```tsx
   ✅ t('dashboard.welcome', { name: user.name })
   ❌ `Welcome back, ${user.name}!`
   ```

3. **Show AI translation notice for non-English content**
   ```tsx
   {isAI && <span>{t('hero.aiTranslatedNotice')}</span>}
   ```

4. **Use meaningful, hierarchical keys**
   ```tsx
   ✅ 'auth.login.errors.emailRequired'
   ❌ 'loginEmailErr'
   ```

5. **Handle missing translations gracefully**
   ```tsx
   const { tWithFallback } = useTranslation();
   tWithFallback('new.key', 'Default text')
   ```

### ❌ DON'T

1. **Don't concatenate translations**
   ```tsx
   ❌ t('contact.email') + ': ' + email
   ✅ Create a dedicated key with parameter
   ```

2. **Don't assume English-only**
   ```tsx
   ❌ const title = "Properties";
   ✅ const title = t('nav.properties');
   ```

3. **Don't use translations for internal logic**
   ```tsx
   ❌ if (t('property.status.available') === 'Available')
   ✅ if (property.status === 'available')
   ```

4. **Don't forget RTL considerations**
   ```tsx
   ✅ Check isRTL() for layout-dependent code
   ❌ Assume left-to-right always
   ```

## Troubleshooting

### Translation Not Showing

**Problem:** Translation key returns the key itself instead of translated text.

**Solutions:**

1. **Check if key exists:**
   ```tsx
   const { hasTranslation, t } = useTranslation();

   if (hasTranslation('my.key')) {
     console.log(t('my.key'));
   } else {
     console.warn('Translation missing: my.key');
   }
   ```

2. **Check console for warnings:**
   The system logs warnings for missing keys:
   ```
   Warning: Translation key not found: hero.missingKey
   ```

3. **Verify key path is correct:**
   ```tsx
   ✅ t('property.types.villa')
   ❌ t('property.type.villa')  // Wrong: 'type' vs 'types'
   ```

### Parameter Not Interpolating

**Problem:** `{name}` shows literally instead of being replaced.

**Solution:** Pass parameters as second argument:

```tsx
❌ t('dashboard.welcome')
✅ t('dashboard.welcome', { name: 'John' })
```

### Wrong Locale Showing

**Problem:** Always shows English even on other locales.

**Solutions:**

1. **Check URL structure:**
   ```
   ✅ /id/properties  (locale in path)
   ❌ /properties     (no locale)
   ```

2. **Verify params are passed correctly:**
   ```tsx
   export default function Page({ params }: { params: { locale: Locale } }) {
     // params.locale should exist
     console.log('Locale:', params.locale);
   }
   ```

### TypeScript Errors

**Problem:** Type errors when using translations.

**Solutions:**

1. **Import Locale type:**
   ```tsx
   import { type Locale } from '@/i18n';
   ```

2. **Ensure Messages interface is up to date:**
   After adding keys, restart TypeScript server in VS Code:
   `Cmd+Shift+P` → "TypeScript: Restart TS Server"

### Performance Issues

**Problem:** Translations slowing down the app.

**Solutions:**

1. **Use direct message access for frequently accessed translations:**
   ```tsx
   const { messages } = useTranslation();
   // Faster than t() for repeated access
   <span>{messages.common.loading}</span>
   ```

2. **Memoize translation results if used in loops:**
   ```tsx
   const bedrooms = useMemo(
     () => t('property.details.bedrooms'),
     [t]
   );
   ```
